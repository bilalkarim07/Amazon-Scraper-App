# Amazon Scraper Suite

A web application for scraping Amazon products from CSV files.

## Features

- Upload CSV files containing Amazon product links
- Configure scraping parameters (column name, batch gap, threads)
- View scraped data in an interactive table
- Download scraped results
- Delete files from the application

## Technology Stack

- **Frontend**: React 19, TanStack Router, TanStack Query
- **Styling**: Tailwind CSS 4, shadcn/ui components
- **Build Tool**: Vite
- **Language**: TypeScript

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm or bun

### Installation

```sh
git clone https://github.com/bilalpersonalacc1-n/shiny-scraper.git
cd shiny-scraper
npm install
```
